# Где работает агент: этот компьютер или облако (шаг 3.6 скилла teamly-v2)

Два места, у каждого агента в записи команды `where`:
- `"local"` — свой чат в приложении на этом компьютере. Работает, пока Claude открыт и компьютер не спит. Доступно всё: файлы, программы, локальные инструменты.
- `"cloud"` — облачная сессия Claude Code. Работает, когда компьютер закрыт. Видит только GitHub-репозиторий команды и интернет.

**Облако можно, только если выполнены все три условия:**
1. в карточке агента `runtime.cloud: true` (у агентов, которым нужны программы на компьютере, например монтаж, — `false`: только локально);
2. у команды есть репозиторий (`repo`: "owner/name") — проверь `mcp__ccd_session__list_start_targets`: папка команды в `repositories`, `cloud.available` или облачная среда под этот репозиторий;
3. человек сам выбрал облако.

**Когда спрашивать.** На этапе «Место и чат» найма (шаг 3.5) и по промпту `Teamly: move <slug> to cloud`. Если пункты 1–2 выполнены — `AskUserQuestion` «Где работает <Имя>?»: «На этом компьютере» / «В облаке — работает, пока компьютер закрыт». Репозитория нет — одной строкой скажи, что для облака нужна приватная репа на GitHub для папки команды, и предложи создать (`gh repo create --private` и первый push — только по его «да»). Иначе — локально, без вопроса.

**Как работает облачный агент.**
- Запуск: `start_session` с `target: "cloud"`, `repository` = `repo`, бриф: работать в папке задачи, результат положить файлом шага и закоммитить в ветку `teamly/<задача>`, строку статуса — в `<задача>/cloud/<slug>.md`. Ключ Teamly не коммитить: он задаётся переменной окружения облачной среды.
- Облачная сессия не пишет в ответ и не будит тебя. Поэтому на каждом ходе человека в этом чате (и по его просьбе «проверь облако») проверяй облачных агентов: `mcp__ccd_session_mgmt__get_session` (не работает — закончил) и `git fetch` ветки → забери файл в папку задачи, обнови STATUS, передай дальше.
- Нужен человек — его вопрос в облачном чате агента: STATUS `waiting for you: <что> (in its cloud chat)`, панель откроет этот чат по «Needs you».
- В записи: `where: "cloud"`, `session` = id облачной сессии. Панель рисует такого агента с облачком.
