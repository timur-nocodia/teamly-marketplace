# Обратная связь и баги — лично основателю

Основатель Teamly — Игорь Косолапов; контакты в `founder.json` рядом с этим скиллом (`telegram`, `email`). Он читает каждое сообщение сам. Человек должен знать, что может написать ему напрямую, особенно когда что-то сломалось.

**Когда предлагать написать Игорю:**
- что-то сломалось и ты не починил с одной попытки: агент дважды упал на шаге, скрипт или сервер панели выдаёт ошибку, установка не прошла, результат явно не тот;
- человек раздражён («не работает», «сломалось», «бесит», «опять»);
- оценка 1–2★;
- промпты из панели `Teamly: report a bug …` и `Teamly: feedback`;
- один раз после первой готовой задачи и один раз через 7 дней: «Что улучшить в Teamly? Игорь, основатель, читает это сам» (можно пропустить — не настаивай).

**Как:**
1. Одной-двумя строками честно: что сломалось и что ты уже попробовал. Без оправданий.
2. `AskUserQuestion` «Отправить это Игорю, основателю Teamly? Он разбирает баги лично.» — «Да, подготовь отчёт» / «Напишу ему сам» / «Не надо».
3. Отчёт: что человек делал, что произошло, что ожидалось, шаг и агент, текст ошибки (обрезанный), версия панели и ОС. **Без** ключей, содержимого файлов, путей к личным папкам и данных клиентов — только то, что нужно, чтобы повторить. Покажи отчёт целиком и спроси «Так отправляем?».
4. Сохрани: `POST http://127.0.0.1:4319/api/feedback` с заголовками `X-Teamly-Panel: 1` и `Origin: http://127.0.0.1:4319` (`{"kind": "bug"|"idea"|"other", "text", "context"}`; `context` — объект: `{"step", "agent", "error", "os"}`, текст тоже сохранится одной строкой) или файлом `~/.teamly/feedback/<время>-<kind>.md`.
5. Отправка — руками человека, пока нет API Teamly: есть `email` — открой письмо `mailto:<email>?subject=Teamly%20bug&body=<коротко + путь к файлу отчёта>` (отправит он сам); есть `telegram` — отчёт в буфер и открой `https://t.me/<handle>`. Команды: macOS — `open "<ссылка>"`, `pbcopy < <файл>`; Windows (Bash в Claude Code — Git Bash) — `cmd //c start "" "<ссылка>"`, `powershell -c "Get-Content -Raw -Encoding UTF8 '<файл>' | Set-Clipboard"` (`clip` портит кириллицу). Сам ничего не отправляй.
6. «Напишу ему сам» — дай контакт из `founder.json` и путь к сохранённому отчёту.
7. В `founder.json` нет ни `email`, ни `telegram` (`null`) — ссылку не выдумывай. Скажи: отчёт сохранён в `<путь>`, перешли его Игорю тем же путём, каким получил Teamly.
