# Внешние инструменты: Data API Teamly

Когда агенту нужно то, чего нет у Claude Code, — точные цифры соцсетей, поиск людей и компаний, SEO, генерация картинок, видео или голоса, — инструмент берётся из Data API Teamly по ключу человека. Там тысячи инструментов от десятков поставщиков (каталог апстрима): скраперы Instagram, TikTok, YouTube, Reddit, Facebook, Telegram, Amazon, Google Reviews; поиск и чтение сайтов (Exa, Firecrawl, Browserbase); люди и компании (Apollo, People Data Labs); SEO (Ahrefs); видео (Seedance, MiniMax), картинки, голос (ElevenLabs); акторы Apify. Платит человек из своих Teamly Dollars, поэтому каждый платный запуск — только после его «да».

Команда: `<python> "<base directory teamly-v2>/data_api.py" <команда>`. Ключ скрипт берёт сам, оттуда же, где его держит панель. Никогда не печатай ключ, не проси вставить его в чат и не пиши в файлы. Нет ключа (`401`) — открой вход, как в шаге 0.2 SKILL.md (`/api/open-url` с `"which": "key"`), и одна строка: «Открыл сайт Teamly в браузере: войди, ключ вернётся сам, и я возьму инструмент».

## Сначала — чем можно без денег

1. Указание человека на эту задачу.
2. Его собственные инструменты: MCP, его ключи, CLI. Не трать его деньги на то, что у него уже есть.
3. Бесплатные инструменты Claude Code: WebSearch, WebFetch, файлы. Хватает — бери их.
4. Data API — для того, что остальные не дают.

## Как брать инструмент

1. **Найди** — `discover "<коротко, существительными>"`: «instagram reels by hashtag», «tiktok videos by keyword», «company employees», «google maps reviews». Бесплатно. Большую задачу раздели на части и ищи каждую отдельно. Среди найденного смотри `score`, цену и здоровье: `healthy` или `stable` лучше `degraded`, но `unknown` не отбрасывай.
2. **Посмотри** — `inspect <provider> <endpoint>`. Бесплатно. Входные поля бери только отсюда, не угадывай.
3. **Цена → «да» человека.** Одним `AskUserQuestion`: какой инструмент, что даст, цена из `inspect` (за вызов или за каждый результат) и лимит («до 20 постов, около $0.20»). Одно «да» — на эту задачу, этот инструмент и этот лимит; другой инструмент или лимит больше — спроси снова. Агент сам не спрашивает: он заканчивает ход строкой `НУЖЕН ЧЕЛОВЕК: <инструмент, что даст, цена, лимит — запускаем?>`, координатор спрашивает человека и присылает ответ.
4. **Запусти** — `run <provider> <endpoint> --input <файл.json> --out "<папка задачи>/data/<что это>.json" --yes`. В `--input` ровно `pathParams`, `queryParams`, `body` из `inspect`. Начинай с малого: 5–10 результатов, один запрос — одна тема; лимиты вроде `maxItems` часто считаются на каждый запрос внутри вызова.
5. **Долгий запуск** — в ответе `next`: проверяй `status <runId> --out <тот же файл>` раз в 5–10 секунд, не чаще.
6. **Результат** — файл в папке задачи; в чат и в отчёт — выжимка с источником. Цена — из ответа (`cost`): впиши в строку шага в `STATUS.md` («инструмент: $0.12») и в отчёт. Вызов сам появится в кошельке панели.

## Ошибки

| Код | Что делать |
|---|---|
| 400 | Поле не подошло: `inspect` ещё раз, исправь названное поле. Бесплатно |
| 401 | Нет ключа Teamly или он не принят — открой вход (шаг 0.2 SKILL.md) и попроси войти на сайте |
| 402 | Не хватает Teamly Dollars — скажи человеку и предложи пополнить на сайте; не повторяй |
| 403 / 422 | Инструмент недоступен или цена неизвестна — возьми другой из `discover` |
| 429 | Слишком часто — подожди `retryAfter` секунд |
| 502 / 503 | Сбой у Teamly или поставщика — повтори через минуту, один раз |
| `BLOCKED` | Сработал лимит сервиса — скажи человеку, попробуй позже |

Ошибки поставщика и неверный ввод не списываются. `httpStatus` в ответе запуска: 200 — данные в файле; 400/404/429/500 — плохой ввод, ничего не нашлось, лимит или сбой поставщика.

## Что искать для агентов библиотеки

- **trend-radar** (Live social data): «instagram reels by hashtag», «tiktok videos by keyword», «youtube channel videos», «x posts by keyword».
- **investor-scout** (Investor databases): «investor database», «company funding rounds», «people search by company».
- **carousel-maker** (Image generation): «image generation».
- Видео и озвучка: «video generation», «text to speech».

Нужного нет — скажи одной строкой, чего не нашлось, и работай бесплатными инструментами.

## Приватность

Отправляй в инструменты только то, что нужно для запроса. Данные клиентов человека, его файлы и переписку не отправляй. О людях — только публичные рабочие данные (компания, должность, публичные профили).

## Агенту в бриф

Если шагу агента нужен платный инструмент, координатор кладёт в бриф три вещи: команду с полным путём к `data_api.py`, правило «цена → `НУЖЕН ЧЕЛОВЕК` → `run --yes` только после ответа» и папку для `--out` (`<папка задачи>/data/`).
