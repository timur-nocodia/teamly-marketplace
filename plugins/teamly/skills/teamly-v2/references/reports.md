# Отчёты команды

Человек видит результат, не спрашивая: команда сама отчитывается с частотой, которую он выбрал. Отчёт — один экран фактов с источниками, а не пересказ переписки. Панель показывает отчёты на этаже и в Overview → Report.

## Настройка (онбординг 1.55, `Teamly: reports setup`)

1. **Частота.** `AskUserQuestion` «Как часто присылать отчёт о работе команды?»: Каждый день (вечером) / Раз в неделю (понедельник утром) / После каждой задачи / Только когда нужен я. Время человек может уточнить в Other.
2. **Система отчёта — предложи сам**, по зоне, цели и агентам команды (шаблоны ниже). Покажи одним экраном: какие цифры, откуда каждая и сколько стоит, что будет в отчёте. Цифра цели — первой: цель «30 рилсов к 22.11» → «опубликовано N из 30». `AskUserQuestion` «Так отчитываемся?»: Да / Поменять (что убрать или добавить). Платный источник — только если человек выбрал его здесь (`approved: true`): тогда отчёт может тратить на него Teamly Dollars без нового вопроса.
3. **Запиши** в запись команды:
   ```json
   "reports": {"cadence": "daily|weekly|task|needs", "at": "19:00 | mon 09:00", "next": "<местные дата и время без смещения, 2026-10-27T19:00>", "last": null,
               "metrics": [{"name": "Views per reel", "source": "TikTok, YouTube: public pages (public_stats.py)", "cost": 0, "approved": true}],
               "links": {"instagram": "<профиль>", "tiktok": "…"}, "scheduled": "<taskId или null>"}
   ```
   Ссылки на профили человека (для цифр по публикациям) спроси одним вопросом, если их нет.
4. **Расписание.** `daily` и `weekly`: если в этом чате есть инструмент запланированных задач приложения (`create_scheduled_task`, загрузи через ToolSearch) — скажи в чат обычным сообщением: «Ставлю отчёт: <когда>. Пиши «да» или другое время» и после напечатанного ответа создай задачу: `taskId` `teamly-report-<slug>`, `title` «Teamly · отчёт <команда>», `cronExpression` по выбору (`0 19 * * *` — каждый день в 19:00, `0 9 * * 1` — понедельник 9:00, местное время), `prompt` — `Teamly: report "<рабочая папка>"` и одной строкой: «составь отчёт этой команды по references/reports.md скилла teamly-v2; платные источники — только с `approved: true`; ничего не публикуй». `taskId` в `reports.scheduled`. Скажи одной строкой: задача идёт, пока открыто приложение Claude; если оно было закрыто — отчёт придёт при следующем запуске. Инструмента нет — расписания не будет: отчёт сделаешь, когда человек придёт в чат после `reports.next` (шаг 0). `task` и `needs` — без расписания.

## Отчёт (`Teamly: report`, по расписанию, или шаг 0, когда `reports.next` прошёл)

`Teamly: report "<папка>"` пришёл из запланированной задачи — работай с командой, у которой `folder` = эта папка (запись в `~/.teamly/teams/`), даже если чат открыт в другой папке.

1. **Собери, что сделано** с прошлого отчёта (`reports.last`): задачи из `tasks` со статусами `STATUS.md`, итоговые файлы шагов.
2. **Собери цифры** по `reports.metrics`: каждая — с источником и датой. Нет цифры — «н/д» и как её получить. Никогда не придумывай и не оценивай на глаз.
3. **Сравни**: с целью (сколько из скольких, успеваем ли к сроку) и с прошлым отчётом (изменение).
4. **Запиши** `<рабочая папка>/reports/<ГГГГ-ММ-ДД>.md` (после задачи — `<ГГГГ-ММ-ДД>-<slug задачи>.md`; файл за этот день уже есть — `<ГГГГ-ММ-ДД>-2.md`, `-3`…: прошлый отчёт не перезаписывай), по-английски в заголовках, на языке человека в тексте:
   ```markdown
   # <Команда> · report <дата>
   ## Done
   ## Numbers        (таблица: metric · now · change · source, date)
   ## What worked · what didn't
   ## Next
   ## Needs you      (если что-то нужно от человека, иначе раздела нет)
   ```
5. В записи команды `reports.last` = сейчас, `reports.next` = следующий срок по `cadence` и `at` в местном времени, без смещения (`2026-10-27T19:00`): так срок не съезжает после перевода часов или перелёта. Шаг 0 не делает отчёт сам, если запланированная задача сработает в ближайший час.
6. В чате — 3–5 строк: главное число, изменение, что дальше, что нужно от человека. Отчёт по расписанию: в чат координатора команды этого не пиши — файл и панель (уведомление о задаче придёт приложению).

`needs` — отчёта по расписанию нет. Напиши человеку сам, только если цель под угрозой (по темпу не успеваем к сроку) или шаг ждёт его больше суток.

## Шаблоны по зонам

**Контент, рилсы, короткое видео.** Цифра цели: опубликовано N из M. По каждому ролику за период: просмотры, лайки, комментарии, сохранения, репосты; новые подписчики, если площадка их показывает; лучший ролик и чем он отличается; серия публикаций без пропусков.
- Что опубликовано: итоговые файлы задач + ссылки на профили человека (`reports.links`).
- TikTok и YouTube Shorts: публичные страницы через `public_stats.py` агента Trend Radar — бесплатно, без входа в аккаунт.
- Instagram: публичные страницы точных цифр не дают. Варианты: живые данные Teamly API по ключу Teamly (≈$0,40 за проверку, только с `approved: true`); скриншот или выгрузка Insights от человека раз в неделю — бесплатно; не считать.
- X: публичный embed через `public_stats.py`: лайки, ответы и время; просмотров X без входа не отдаёт — их не будет.
- Никогда не входи в соцсети паролем или cookies человека и не собирай данные чужих людей.

**Фандрейзинг.** Найдено инвесторов, написано, ответили, созвоны назначены, этапы воронки, следующие касания с датами. Источник: файлы команды (вывод Investor Scout, трекер), выгрузка CRM от человека.

**Планирование.** План против факта по задачам, доля времени на главную цель, что сдвинулось и почему.

**Другие зоны** (юристы, продажи, найм). Сделанные результаты против плана; цифры, которые человек уже ведёт сам (спроси, где они); сроки и что под угрозой.
